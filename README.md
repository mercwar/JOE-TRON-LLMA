## ⚡ Quick Deployment

Clone the core module into your local developer workspace and compile against your native UCRT64 toolchain:

```bash
git clone https://github.com/mercwar/JOE-TRON-LLMA.git
cd JOE-TRON-LLMA
gcc core_dispatch.c -o joe-tron-core.exe -I./include -L./lib -luser32 -lkernel32 -llama -lggml

```
