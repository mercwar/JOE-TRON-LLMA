## ⚡ Quick Deployment

Clone the core module into your local developer environment and compile directly against your native Windows UCRT64 toolchain:

```bash
# Clone the repository
git clone [https://github.com/mercwar/JOE-TRON-LLMA.git](https://github.com/mercwar/JOE-TRON-LLMA.git)
cd JOE-TRON-LLMA

# Compile native binary via GCC
gcc core_dispatch.c -o joe-tron-core.exe -I./include -L./lib -luser32 -lkernel32 -llama -lggml

# Execute local runtime
./joe-tron-core.exe

```
